# Vehicle Options Elite (VOE)

Welcome to **Vehicle Options Elite** — a modular vehicle enhancement ecosystem built for Roblox developers who want their vehicles to feel more alive, interactive, and immersive without spending weeks building every system from scratch.

VOE is designed around a simple philosophy:

> Start simple. Scale up when you're ready.

Whether you just want functional headlights and turn signals, or you want fully articulated doors, rolling windows, animated exhaust systems, and persistent fuel simulation — VOE is built to grow with your project.

---

# What Is VOE?

VOE is a collection of modular plugin systems focused on:

- Vehicle realism
- Immersion
- Interaction
- Articulation
- Lighting
- Simulation

Everything is designed to be:

- Modular
- Expandable
- Developer-friendly
- Easy to integrate
- Easy to maintain

The ecosystem is broken into several major categories depending on how advanced your project needs are.

---

# VOE Lighting

VOE Lighting is the entry-level package and the easiest place to start.

This package is intentionally lightweight and simple:

- Drop the plugins in
- Apply your tags
- Run the system

No weld reconstruction.  
No articulation setup.  
No complicated bootstrap pipeline.

Just quick, clean vehicle lighting systems that instantly make your vehicles feel more complete.

## Included Systems

- Headlights
- Turn Signals
- Fog Lights
- Dome Light
- Reflectors
- Underglow
- Emergency Lights

## Best For

- Starter vehicle projects
- Roleplay games
- City games
- Emergency response games
- Developers wanting quick visual upgrades

# VOE Articulates Core

VOE Articulates Core is where the real vehicle interaction framework begins.

This package introduces the articulation bootstrap system.

Unlike lighting systems, articulation systems require:

- Weld reconstruction
- Constraints
- Movement assemblies
- Runtime articulation handling

The included bootstrap scripts automatically prepare the vehicle by:

- Breaking original welds
- Rebuilding articulation assemblies
- Adding required constraints
- Preparing the vehicle for movable systems

Once this setup is installed, future articulation plugins become mostly drop-in and ready to go.

## Included Systems

- Doors
- Hood
- Trunk
- Windows
- Sunroof

## Purpose

This package forms the foundation for all advanced movable vehicle systems.

One of the biggest goals of VOE is flexibility.

- Lighting systems

- Full articulation
- Simulation
- Persistent mechanics

---

# System Dependencies

Some systems are standalone.

Others integrate with or enhance existing systems.

For example:

- Puddle Lights become more useful when Doors are installed
- Popups rely on Headlights
- Dome Lights can operate independently or react to door states
- Spotlights can function statically or become fully articulated

This layered approach keeps the ecosystem flexible while still allowing advanced integrations.
